# Cockpit — UI Source Reference

**Upstream:** https://github.com/cockpit-project/cockpit

Cockpit is the strongest reference here for a lightweight operating-system administration UI. Its documented scope includes storage administration, network configuration, logs, containers, system metrics, and host administration. It is designed to interact with a real Linux session through a browser. The project also has a dedicated VM UI in `cockpit-machines`.

**License note:** Cockpit's repository reports multiple licenses, including LGPL-2.1-or-later, GPL-3.0-or-later, BSD-3-Clause, CC-BY-SA-3.0, and MIT. Individual files must therefore be checked before reuse.

**White Edition use:** architectural reference for Host, Kernel, Storage, Process, Network, VM, Log, and Stability surfaces.
