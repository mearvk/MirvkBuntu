# OpenBao — Authority UI Source Reference

**Upstream:** https://github.com/openbao/openbao
**UI:** https://github.com/openbao/openbao/tree/main/ui

OpenBao is the strongest reference for the identity/policy side of the proposed authority UI. Its project describes identity-based secrets and encryption management, authentication/authorization, and auditable access. Its repository contains a dedicated Ember UI and documents building the UI into the application binary.

**License:** MPL-2.0 for OpenBao's project as identified by its repository metadata/API documentation.

**White Edition use:** architectural reference for Identity, Policy, Authorization, Audit, Credential, and Security surfaces.

**Acquisition status:** source registered; not vendored into this repository.
