# GitLab — Source-Control UI Reference

**Reference:** https://docs.gitlab.com/user/project/web_ide/

GitLab's Web IDE is a strong reference for source-control-centered interaction. Its documented workflow includes modified-file review, staging, branch switching/creation, commits, and merge-oriented source control.

**White Edition use:** architectural reference for Source, Change, Branch, Review, Commit, Provenance, and Evidence surfaces.

This document references the documented UI behavior rather than copying GitLab source code. Any future source import must independently verify the applicable GitLab repository licensing and preserve required notices.
