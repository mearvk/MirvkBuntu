# Ubuntu White Representative Icon Set

This directory is the canonical location for representative Ubuntu White desktop icon assets used by the `/main/isolation-desktop` preview.

## Source policy

The repository wallpaper is the canonical Ubuntu White visual reference. For standard Ubuntu iconography, use Ubuntu's published design resources and the installed Ubuntu icon theme where licensing permits. Ubuntu's design system publishes an icon library and related brand resources.

The preview must not silently substitute unrelated icon themes. Each checked-in artwork should have its provenance recorded here or beside the asset.
