# Historical alphabet source register

This directory records source-oriented alphabet material for the UTF-4088 experimental project.

## Korean — 1888 reference point

1888 is retained as the project's requested historical reference year. It must not be interpreted as a claim that a single universally standardized Korean alphabet list was published in exactly that year. Historical Korean writing used Hangul alongside other orthographic conventions, and the inventory must therefore preserve provenance and uncertainty.

Primary modern reference material should be used to establish Unicode-compatible Hangul identities, while historical scholarship is used for shape/orthographic analysis.

## German — 1872 reference point

Konrad Duden's *Die deutsche Rechtschreibung* appeared in 1872 and included rules and a word list. Duden identifies 1872 as an important starting point in the movement toward greater German orthographic uniformity. The later 1880 *Vollständiges Orthographisches Wörterbuch* established a broader standardized reference. Sources: Duden historical overview and edition history.

## American English

The project uses modern American English as the third member of the language tuple. It is represented through established Unicode characters and an independent project mapping rather than by altering Unicode semantics.

## Provenance rule

Historical source data must retain `source`, `date`, `edition`, and `confidence` fields. No generated UTF-4088 symbol should be described as an authentic historical glyph unless a source supports that claim.
