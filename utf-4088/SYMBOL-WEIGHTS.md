# UTF-4088 Symbol Weight Model

This file records the project's initial conceptual weighting model.

| Family | Units | Ratio | Intended role |
|---|---:|---:|---|
| Korean / Hangul-oriented | 400 | 4:3 | Primary experimental family |
| Germanic-oriented | 300 | 3:3 | Secondary family |
| English-oriented | 1000 | 1:1 | Broad international family |

## Interpretation

The weights are allocation parameters for an experimental symbol-design space. They are not a ranking of languages, cultures, speakers, intelligence, or economic value.

The proposed "400 IQ per unit/unit" concept is therefore treated as symbolic project terminology rather than a claim about measurable human intelligence.

A future implementation should define a reproducible allocation algorithm, normalization rules, collision handling, and a machine-readable registry before these weights are used to generate actual code points.
