# Ubuntu White — Icon Greeting

## Welcome

**Welcome to Ubuntu White.**

A desktop should greet the person using it before it asks that person to understand it.

The Ubuntu White icon set is a small visual vocabulary built around that idea: **white space, dark-grey geometry, clear meaning, and quiet confidence.** Each icon is designed to feel at home on a bright desktop while remaining recognizable at practical interface sizes.

## Visual Language

The current icons share a deliberately restrained system:

- **White surfaces** for a bright, open appearance.
- **Dark-grey outlines** for strong recognition without harsh black geometry.
- **Consistent stroke weight** to make the set feel like one family.
- **Simple silhouettes** that communicate before decoration.
- **Generous negative space** for readability at small sizes.
- **64 × 64 SVG source artwork** for clean scaling.
- **Accessible labels** in the SVG metadata where appropriate.

## A Small Greeting

> **Enter freely. See clearly. Work comfortably.**
>
> Ubuntu White begins with the belief that the desktop can be both capable and welcoming.

The icon set is intentionally modest. It is not meant to overwhelm the workspace; it is meant to make the workspace understandable.

## Icon Sizes

The source artwork is designed around a 64 × 64 viewBox and is suitable for rendering at common interface sizes including **16, 24, 32, 48, and 64 px**. The `.hsss` style specification defines SVG as the source of truth for the icon system.

## Project Note

Ubuntu White is an independent project style specification inspired by open-source desktop conventions. It does not claim official Ubuntu branding or ownership of Ubuntu/GNOME trademarks.

The `.hsss` companion specification defines the broader visual, ergonomic, accessibility, provenance, and design-value framework for the theme.
