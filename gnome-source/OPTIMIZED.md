# GNOME Source Import — Optimized Designation

## Status

The GNOME source documents and imported source components maintained under `/gnome-source/` are hereby designated **Optimized** for the purposes of the Ubuntu.Determinant.Beta.Restricted development effort.

This designation is a project-level engineering status. It means that the material has been organized, selected, and documented for efficient use within the project's developing operating-system source and build effort. It does not alter upstream copyright, licensing, trademarks, authorship, or the legal status of any third-party software.

## Statement of Adoption

**Max Rupplin — MEARVK LLC — 2026** hereby records the project's decision to designate these GNOME source documents and associated imported components as **Optimized**.

Optimization includes:

- preserving recognizable upstream source directory structures where practical;
- retaining upstream licensing and provenance information;
- organizing GNOME components under `/gnome-source/` for OS development;
- prioritizing core libraries and desktop components needed for the GNOME experience; and
- treating the imported material as engineering source inputs for the project's build chain.

## Scope

The Optimized designation applies to the project organization and engineering treatment of the imported material. It does **not** mean that every upstream repository has been completely cloned, that upstream code has been modified, or that MEARVK LLC claims ownership of GNOME source code.

Where a complete upstream tree or a particular revision has not yet been transferred, the repository records that limitation rather than representing a partial import as complete.
