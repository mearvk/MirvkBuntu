# Mutter — Upstream README Record

Mutter is a Wayland display server running on KMS and libinput. It implements the compositor side of the Wayland core protocol and extensions, and supports X11 applications through Xwayland. It provides window management, compositing, focus tracking, workspaces, keybindings, and monitor configuration. Mutter is used by GNOME Shell and is distributed under the GNU General Public License, version 2 or later.
